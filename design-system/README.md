# Design system Creatabl.ia

Référence visuelle commune au site web et à la plateforme.

- Version interactive (composants, pages d'exemple, logos) : https://claude.ai/artifact/4MbDbLwEx4iNcghpSo3EKf
- `GUIDE.md` : guide de marque (ton, couleurs, typographie, espacements, états, icônes).
- `tokens.json` : tokens sources (couleurs, typographie, espacements, rayons, ombres).
- `tokens.css` : les mêmes tokens en variables CSS.

Règles essentielles :

- Thème clair uniquement. Fond `#FFFFFF`, sections `#F8F7FC`, texte `#14121F`, texte secondaire `#4B4B63`, bordures `#E8E6F0`.
- Violet d'action `#7225E3` ; dégradé `#7225E3 → #8A38F5` réservé aux boutons principaux et au hero ; `#7C3AED` pour les accents de la plateforme connectée.
- Titres en Outfit 600/700, texte en Inter 400/500/600, un seul mot en Playfair Display italique par titre.
- Rayons : 12px pour les cartes et champs, pilule (999px) pour les boutons et tags. Deux niveaux d'ombre.
- Crédits : 1 crédit = 1 post programmé ou publié (Free 20, Starter 50, Pro 120, Business 300 par mois).
